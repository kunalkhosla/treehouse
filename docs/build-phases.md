# Build phases + checklists

## Phase 0 — Confirm (do first)

- [ ] Confirm tree species (leaf opposite/alternate, or nut) — see `tree-id.md`
- [ ] If ash: rule out EAB (D-holes, dieback, blonding). If unhealthy → pick another tree.
- [ ] Confirm no irrigation lateral runs under the 6 footing spots (Rachio zones)
- [ ] Mark the 8×8 footprint with stakes + string; check it's square and clears the second trunk
- [ ] Site-specific checks → see local notes (kept out of version control)

## Phase 1 — The platform (the weekend job)

1. **Footings**
   - [ ] Dig 6 holes (~42" deep) on the 0/4/8 grid, uphill + downhill lines
   - [ ] Gravel base, set tube forms, pour concrete, set ABU66 bases plumb, let cure
2. **Posts**
   - [ ] Stand 6×6 posts in bases
   - [ ] Mark one level line around all 6 (laser/water level), cut tops
3. **Beams**
   - [ ] Build two doubled 2×8 beams, bolt to post tops (uphill + downhill edges)
   - [ ] Add 4×4 knee braces (45°), especially the tall downhill posts
4. **Joists + tree opening**
   - [ ] Hang 2×8 joists @16" oc between beams
   - [ ] Frame the 26"×26" tree opening: doubled trimmers + doubled headers, ~4" gap to bark
5. **Deck**
   - [ ] Lay 5/4 decking with ~1/4" gaps; notch around the trunk
6. **Railing + access**
   - [ ] 4×4 rail posts bolted to rim; 36" rails; 2×2 balusters <4" gap
   - [ ] Uphill step(s); downhill ladder (optional)
7. **Done check**
   - [ ] Wobble test (jump on it), all bolts tight, no protruding screws, no sharp edges
   - [ ] Photos → `docs/photos/`, update `log.md`

## Phase 2 — Make it a clubhouse (later)

- [ ] Shed roof (single slope) or shade canopy
- [ ] Half-walls / walls with a window cutout
- [ ] Trapdoor entry + ladder
- [ ] Sandbox or storage in the open downhill bay

## Phase 3 — The fun stuff (extensible)

- [ ] Climbing wall or cargo net on the downhill face
- [ ] Small slide off the deck
- [ ] Rope bridge / zipline to the second tree
- [ ] (Optional) add a real tree attachment with TABs to "hug" the trunk

## Safety standing rules

- Railing 36"+, baluster gaps <4", everywhere except the active entry
- Recessed/flush fasteners; no exposed bolt threads at kid height (cap them)
- Re-check the bark gap and re-tighten bolts each spring as the tree grows
